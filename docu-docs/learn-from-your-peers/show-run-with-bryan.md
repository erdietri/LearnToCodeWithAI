# Get Show Commands with Bryan

Ever wanted someone to handhold you through a script? This is that video. In this informal conversation with Bryan Dufresne, a network engineer, and Erika Dietrick, a software engineer, we walk you through Bryan's script that pulls the 'show run' and 'show ver' of a group of switches. You'll learn how what we've covered in the course so far applies to a real world automation example, how we think through solving problems programmatically, where AI fits into the picture, and more.
