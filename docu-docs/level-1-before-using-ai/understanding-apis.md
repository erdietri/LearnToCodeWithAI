# Understanding API Calls

There are multiple ways to interact with a product or service. Some products allow you to interact with them using the CLI; others provide a way to interact with them through code, called an API. Using an API is tricky at first, but once you get the hang of API calls, you'll use them over and over again!

## Practice what you preach

As shown in the video, choose a free API of your choice and write an API 'GET' call using the API documentation. Then, run the script and answer the questions below.

Did the API require you to authenticate? If so, how?
Did you get a 200 Success response? 
Was other data returned?
What format was the response in? (i.e. JSON, YAML)
How did your API call differ from the one in the video?

## Have your mentor ask you this...
What challenges did you run into when writing this API call?

How might you use the data that was returned in the response in your automation? 

What questions do you have about handling the response data?
