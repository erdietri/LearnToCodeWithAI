# Git Essentials

Coding doesn't happen in a vaccum. We need to be able to track changes in our code over time and to share our code with others. This video explains how to do that by leveraging versional control software (git) and a remote repository (GitHub).

## Practice what you preach

Let's push your first script to GitHub!

Write some code in your developer environment - it doesn't have to run yet or be anything crazy.

Save it.

Create a repository in GitHub.

Once you've installed git, see if you can remember the commands from the video used to clone the repository locally and push your code remotely!

...REMEMBER, even most developers aren't git experts; we just learn the commands we need to to get by. You've got this!!!! (And if you run into errors while doing this, don't panic; it happens!)
